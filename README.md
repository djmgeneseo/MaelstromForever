### What you’ll see

A panel sits near the bottom of the screen (150 pixels or so up from the bottom edge). It has a lightning-bolt medallion on the left, five circular orbs in the middle and a big stack counter on the right.
Each Maelstrom Weapon stack fills an orb. The colour shifts from shaman blue to electric cyan as stacks build.
The glow, edge lines and pulse speed all grow with each stack.
At 5 stacks everything turns gold-white, a shockwave bursts out, and the caption reads “UNLEASH THE STORM”.
When you spend the stacks, the medallion flashes and the orbs discharge.
It only appears while you have stacks, and only for Shamans.

### Commands (/msf):

- /msf test plays a demo from 0 to 5 stacks and back. Use this first to see the effects without needing procs.
- /msf unlock and /msf lock let you drag the panel to a new spot.
- /msf scale <0.5–2.5> resizes it, and /msf always toggles showing the empty tracker.
- /msf reset restores the default position and scale.
- /msf debug lists your buffs and marks the one being tracked, and /msf id <spellID> adds a spell ID to track.
